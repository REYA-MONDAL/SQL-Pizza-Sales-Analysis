# 🍕 SQL Pizza Sales Analysis

## 📌 Project Overview

This project analyzes a pizza restaurant's sales data using SQL to uncover valuable business insights. The analysis focuses on customer ordering behavior, revenue trends, pizza popularity, category performance, and sales distribution.

---

## 🎯 Problem Statement

Pizza restaurants generate thousands of transactions every month, making it difficult to manually identify sales trends and customer preferences.

The objective of this project is to analyze pizza sales data using SQL and answer important business questions such as:

- How many orders were placed?
- What is the total revenue?
- Which pizzas generate the highest revenue?
- Which pizza sizes are most popular?
- What are the busiest hours?
- Which pizza categories perform the best?

The insights help improve menu planning, inventory management, pricing strategies, and overall business decision-making.

## 📈 Key Insights

- Large pizzas were the most ordered size.
- Classic pizzas received the highest number of orders.
- Lunch and dinner hours generated the most sales.
- Premium pizzas contributed significantly to revenue.
- Revenue trends helped identify top-performing products.
